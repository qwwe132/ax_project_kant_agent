# 평가셋 작성 안내

질문, 기대 답변, 허용 근거를 기록하는 JSON 파일의 공통 형식과 채점 기준입니다.

| 파일 | 구성 |
| --- | --- |
| `dev.json` | 10문항. 답변 가능 8문항, 근거 없음 2문항 |
| `test.json` | 20문항. 직접 검색 10문항, 표현 변형·유사 조건 구분 7문항, 근거 없음 3문항 |

## 문항 필드

| 필드 | 작성 내용 |
| --- | --- |
| `id` | 두 파일 전체에서 고유한 질문 ID |
| `type` | 직접 검색, 표현 변형, 유사 조건 구분, 근거 없음 등 문항 유형 |
| `question` | 사용자가 입력할 질문 |
| `expected_answer` | 답변에 반드시 들어가야 할 핵심 사실 또는 정보 부족 안내 |
| `allowed_evidence` | 허용 문서 ID, 청크 ID, 페이지·절·행 등 원문 위치. 근거 없음 문항은 빈 배열 |
| `absence_reason` | 근거 없음으로 판정한 이유. 답변 가능 문항은 생략 가능 |

## 고정 및 채점

- 평가 버전과 연결된 문서·청크 버전: <작성>
- 개발셋으로 튜닝하고 최종 평가셋을 실행 전에 고정합니다. 평가 정답표는 검색 색인과 답변 프롬프트에서 제외합니다.
- 답변 가능 17문항은 Hit@5, 정답 충족, 근거 적합을 각각 0/1로 채점합니다.
- 근거 없음 3문항은 정보 부족 안내를 0/1로 채점합니다. 호출 오류는 0점입니다.
