# 평가셋 작성 안내

질문, 기대 답변, 허용 근거를 기록하는 JSON 파일의 공통 형식과 채점 기준입니다.

| 파일 | 구성 |
| --- | --- |
| `dev.json` | 10문항. 답변 가능 8문항, 근거 없음 2문항 |
| `test.json` | 20문항. 직접 검색 10문항, 표현 변형·유사 조건 구분 7문항, 근거 없음 3문항 |
| `sample.json` | 가상 원문과 연결한 통합 확인용 4문항. [팀 공용 샘플 사용법](../README.md#팀-공용-샘플-데이터)을 참고하세요. |

## 문항 필드

| 필드 | 작성 내용 |
| --- | --- |
| `id` | 두 파일 전체에서 고유한 질문 ID |
| `type` | 직접 검색, 표현 변형, 유사 조건 구분, 근거 없음 등 문항 유형 |
| `question` | 사용자가 입력할 질문 |
| `expected_answer` | 답변에 들어가야 할 핵심 사실 또는 정보 부족 안내를 담은 문자열 배열 |
| `allowed_evidence` | `document_id`, `chunk_id`, `source_location`으로 구성된 근거 배열. 근거 없음 문항은 빈 배열 |
| `absence_reason` | 근거 없음으로 판정한 이유. 답변 가능 문항은 생략 가능 |

## 고정 및 채점

- 2026-11-23 수집 Notion 원문 및 KANT AX 시간표 기준 초안입니다. 문서 ID는 [출처 목록](../data/sources.md)과 연결됩니다.
- `chunk_id`는 `data/processed/chunks.json`(394청크, 커밋 `40d4073`, PR #17 청킹 기준)으로 매핑했습니다. 근거가 여러 청크에 걸치면 청크마다 한 항목씩 넣었고, 하나라도 상위 5개에 있으면 Hit@5는 1점입니다. `source_location`은 해당 청크의 메타데이터 값과 같습니다.
- 근거 청크는 청크 하나만으로도 기대 답변의 사실을 뒷받침하는 것만 넣었습니다. 같은 사실이 여러 문서에 있으면(예: 부정출결 내용이 NOTION-013·015·016에 모두 있음) 문서마다 해당 청크를 모두 넣었고, 키워드만 겹치고 정답 사실이 없는 청크는 넣지 않았습니다. 근거 항목은 개발셋 9개(문항당 평균 1.1개), 최종 평가셋 42개(문항당 평균 2.5개)입니다.
- 청킹·원문이 바뀌면 `chunk_id`가 달라지므로 매핑을 다시 확인하고, 최종 실행 전에 문서·청크·평가셋 버전을 고정합니다.
- 개발셋으로 튜닝하고 최종 평가셋을 실행 전에 고정합니다. 평가 정답표는 검색 색인과 답변 프롬프트에서 제외합니다.
- 답변 가능 17문항은 Hit@5, 정답 충족, 근거 적합을 각각 0/1로 채점합니다.
- 근거 없음 3문항은 정보 부족 안내를 0/1로 채점합니다. 호출 오류는 0점입니다.
